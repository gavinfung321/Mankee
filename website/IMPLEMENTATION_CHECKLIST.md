# Implementation checklist

Each homepage section gets its own file. This list only points at those files.

Before coding a section, add two things:

1. `docs/sections/<section>/<section title>.md` — the checklist and the design plan for that section only.
2. A GitHub issue — summary, link to that file, acceptance criteria. Label it `design`.

Tick a step in the section file when it is accepted on http://localhost:3000/. Do not open a second plan for the same section.
