# Mankee website

Astro and TypeScript workspace for the production site. Commands are run from this directory.

| Command                | Action                                        |
| ---------------------- | --------------------------------------------- |
| `npm install`          | Install dependencies                          |
| `npm run dev`          | Start the local site at `localhost:4321`      |
| `npm run build`        | Build the static site into `dist/`            |
| `npm run preview`      | Preview the production build                  |
| `npm run format`       | Format the project with Prettier              |
| `npm run format:check` | Check formatting without writing files        |
| `npm run lint`         | Lint Astro and script files with ESLint       |
| `npm test`             | Check the scaffold routes, layout, and tokens |

## Fonts

Display: `"Noto Serif TC", "Source Han Serif TC", "PMingLiU", serif`.

Text and controls: `"Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif`.

Noto Serif TC and Noto Sans TC are licensed under the SIL Open Font License, Version 1.1. No font files are shipped yet. Self-hosted WOFF2 subsets wait until the approved copy is locked. PingFang TC and Microsoft JhengHei are local fallbacks and are not redistributed.

Section components, content copy, islands, and Hero media are added in later issues.
